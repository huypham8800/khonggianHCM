# Không gian văn hóa Hồ Chí Minh – Agribank Chi nhánh Lào Cai

Bản xuất từ phiên bản website 8, ngày 30/09/2026. HTML/CSS tĩnh, không cần build, backend hay cài thư viện.

## Đưa lên GitHub Pages
1. Giải nén ZIP.
2. Upload toàn bộ tệp và thư mục bên trong vào repository `huypham8800/khonggianHCM`, nhánh `main`. `index.html`, `style.css` và thư mục `assets` phải ở ngay thư mục gốc repository, không nằm trong thư mục con hoặc trong file ZIP.
3. Vào Settings → Pages → Build and deployment → Source: Deploy from a branch.
4. Chọn nhánh `main`, thư mục `/(root)`, nhấn Save.
5. Đợi GitHub hoàn tất xuất bản, truy cập https://huypham8800.github.io/khonggianHCM/.
